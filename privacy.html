Privacy policy

Last updated: 29 October 2026

Lisa is a private assistant used by one person, its owner, on a computer the owner controls. Only the owner's own Google account is connected.

What Lisa accesses

With the owner's consent, Lisa uses the Gmail API to read the owner's messages, apply labels, archive messages, and create draft replies. A message is sent only after the owner approves it with a tap.

How data is used and stored

Data is processed on the owner's home computer and used only to assist the owner. Short excerpts may be sent to an AI model provider (Anthropic) to summarise messages and write drafts. Data is not sold, shared with advertisers, or used for any other purpose.

Lisa's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke Lisa's access at any time at myaccount.google.com/permissions.
